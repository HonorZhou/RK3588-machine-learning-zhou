# RK3588 仿真模拟学习方案

## 核心结论
不用买板子就能学嵌入式 Linux/U-Boot/驱动开发，通过 QEMU + Buildroot + Renode 三层仿真方案，零成本、不怕变砖、可反复折腾。

## 方案一：QEMU 模拟器（最推荐入门）

### U-Boot 学习
```bash
apt install qemu-system-aarch64
git clone https://github.com/u-boot/u-boot
cd u-boot
make qemu_arm64_defconfig
make CROSS_COMPILE=aarch64-linux-gnu- -j$(nproc)
qemu-system-aarch64 -machine virt -nographic -bios u-boot.bin
```
能学：U-Boot 命令行、环境变量、启动流程、网络启动、设备树加载

### 完整 Linux 系统
```bash
git clone https://github.com/buildroot/buildroot
cd buildroot
make qemu_aarch64_virt_defconfig
make -j$(nproc)
qemu-system-aarch64 -machine virt -nographic \
  -kernel output/images/Image \
  -dtb output/images/qemu-aarch64-virt.dtb \
  -append "root=/dev/vda console=ttyAMA0" \
  -drive file=output/images/rootfs.ext4,format=raw,if=virtio
```
能学：完整启动链、内核配置、驱动加载、设备树调试、Buildroot 构建

## 方案二：Renode 仿真（更贴近真实硬件）
- 专门为嵌入式开发设计的仿真器
- 可模拟具体外设（I2C/SPI/UART/GPIO）
- 可注入传感器数据（模拟 IMU 输出）
- 支持时序调试和多节点联合仿真
- 安装：`pip install renode`

## 方案三：RK3588 专属仿真
- 瑞芯微官方在 rockchip-linux/build 仓库有 QEMU 相关脚本
- Renode 社区正在完善 RK3588 支持

## 仿真实践路线

### 第一阶段：U-Boot 学习（QEMU）
- 编译 U-Boot for QEMU → 启动交互命令行
- 练习 help/printenv/setenv/saveenv/bdinfo/reset

### 第二阶段：内核 + 驱动学习（QEMU + Buildroot）
- Buildroot 一键构建 U-Boot + Kernel + Rootfs
- 进入 Linux 后练习 ls /sys/class/、cat /proc/iomem、dmesg、insmod

### 第三阶段：写虚拟驱动（QEMU）
- 写最简单的 I2C 内核模块（my_i2c_driver.c）
- 在 QEMU 设备树里加虚拟 I2C 设备节点
- insmod 加载 → dmesg 查看 probe 调用

### 第四阶段：GDB 远程调试内核
- QEMU + GDB 远程调试内核/驱动执行流程

## 工具链总结
| 工具 | 用途 | 难度 | 推荐度 |
|------|------|------|--------|
| QEMU | 模拟 ARM64 + U-Boot + Linux | ⭐⭐ | ⭐⭐⭐⭐⭐ |
| Buildroot | 一键构建完整系统 | ⭐⭐ | ⭐⭐⭐⭐⭐ |
| Renode | 嵌入式专用仿真器 | ⭐⭐⭐ | ⭐⭐⭐⭐ |
| GDB + QEMU | 内核/驱动调试 | ⭐⭐⭐ | ⭐⭐⭐⭐ |

## 起步路径
- 第1天：装 QEMU + 编译 U-Boot → 在命令行里玩
- 第2-3天：Buildroot 构建完整 Linux → 启动进系统
- 第4-5天：写 hello world 内核模块 → insmod 加载
- 第7天：写虚拟 I2C 驱动 + 设备树节点 → dmesg 验证
- 第10天：GDB 远程调试内核

## 关键结论
QEMU 上跑通的流程，换到真实板子上几乎一样，只是换 defconfig 和设备树。
