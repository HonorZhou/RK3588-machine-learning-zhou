# RK3588 自制开发板硬件设计指南

## 一、自己画 RK3588 PCB 可行吗？

**可行，但难度不小。** RK3588 是 8nm 工艺、0.5mm pitch BGA 封装，1000+ 引脚，属于高速高密度 PCB 设计。需要：
- **EDA 软件**：Cadence Allegro（官方参考设计用此）或 Altium Designer
- **PCB 层数**：最少 8 层，推荐 10-12 层（DDR4 高速信号 + 3.3V/1.8V/0.8V 多路电源）
- **制造工艺**：HDI 盲埋孔、阻抗控制（50Ω/90Ω差分）、BGA 扇出

## 二、官方参考设计（最重要！）

- **来源**：瑞芯微官方提供 V1.3 版硬件设计指南

- **基于项目**：网络硬盘录像机（NVR）设计，可作为参考电路
- **获取方式**：联系瑞芯微或代理商申请，部分可在 CSDN/博客找到分享

### 2. 吴川斌博客分享
- **地址**：https://www.mr-wu.cn/rk3588-soc-development-resources/
- **内容**：RK3588 硬件参考设计，包括原理图、PCB 数据手册
- **说明**：老吴分享的资料在硬件圈口碑不错

### 3. RK3588 EVB 官方开发板原理图
- **CSDN 讲解**：搜索「RK3588 EVB开发板原理图讲解」

## 三、最小系统设计要点

### 1. 时钟电路
- **系统主时钟**：24MHz 外置晶体
  - XOUT24M 串接 22Ω 限流电阻
  - XIN24M 与 XOUT24M 之间 510KΩ 电阻不可修改
  - 负载电容：COG/NPO 材质，总电容值 <12pF，频率容限 <20ppm
- **待机时钟**：32.768KHz
  - 外部输入或 PMU 内置振荡环
  - 频率偏差 ±30ppm，工作温度 -20~80℃

### 2. 复位与启动配置
- **硬件复位**：NPOR_u 管脚，低电平有效
  - 串联 100nF 去耦电容消除抖动
  - 复位时间 ≥ 4μs（100 个 24MHz 时钟周期）
- **启动配置**：SARADC_IN0_BOOT 管脚上下拉电阻配置 7 种引导顺序
  - 支持：FSPI Flash、eMMC、SDMMC
  - **注意**：RK3588 不支持 PCIe 启动

### 3. 电源方案
- **双 PMIC 方案**：RK806-2（官方 EVB 使用）
- **单 PMIC 方案**：RK806-1（部分核心板使用）
- **上电时序**：由 RK806 管控，硬件工程师只需考虑开关机按键和默认开机
- **核心电压**：VCC_CORE 由 PMIC 供电，需严格按原厂参考设计

### 4. DDR4 设计
- **支持类型**：LPDDR4/LPDDR4X/LPDDR5，4 通道
- **布局要求**：
  - DDR 颗粒尽量靠近 RK3588
  - 地址/命令线等长控制
  - 数据线分组走线，阻抗 50Ω
  - 差分时钟对 DQS/DQS_N 阻抗 100Ω差分
- **信号完整性**：需要仿真验证（HyperLynx/ADS）

### 5. eMMC / SPI Flash
- eMMC 最高 256GB
- SPI Flash 用于启动引导
- 布局靠近 SoC，走线短且等长

## 四、PCB Layout 关键规则

### 1. 叠层设计（推荐 10 层）
```
Layer 1  : TOP        — 元件面 + 高速信号
Layer 2  : GND        — 完整地平面
Layer 3  : SIG1       — 高速信号
Layer 4  : VCC_CORE   — 核心电源平面
Layer 5  : GND        — 地平面
Layer 6  : SIG2       — DDR 信号
Layer 7  : GND        — 地平面
Layer 8  : VCC_DDR    — DDR 电源平面
Layer 9  : GND        — 地平面
Layer 10 : BOTTOM     — 元件面 + 信号
```

### 2. 音频信号
- 所有 CLK 信号串接 22Ω，靠近 RK3588 放置
- CLK 信号独立包地，间隔 300mil 内必须有地过孔
- SPDIF 信号全程包地
- 音频信号远离 DDR、HDMI、USB 等高速信号
- TVS 保护二极管靠近连接座放置

### 3. WiFi/BT 模块
- 模组远离 DDR、HDMI、USB、LCD 电路及喇叭
- 天线区域下方禁止铺铜
- RF 走线 50Ω 阻抗控制

### 4. USB / PCIe / SATA
- 高速差分对 90Ω 差分阻抗
- 等长控制：±5mil
- 尽量少打过孔，必须换层时加地回流孔

### 5. DDR4 走线
- 数据线按字节分组，每组 8 条数据线 + 1 对 DQS
- 地址/命令线一组
- 所有 DDR 信号严格等长（误差 ±50mil）
- DDR 走线参考层必须是完整地平面

## 五、从零开发的步骤

### 步骤 1：获取官方资料
- 联系瑞芯微或代理商获取 RK3588 硬件设计指南（V1.3+）
- 获取官方参考设计原理图和 PCB（Cadence 格式）
- 获取 RK3588 数据手册和寄存器手册

### 步骤 2：设计原理图
- 基于官方参考设计修改
- 根据需求裁剪外设（去掉不用的接口）
- 确认电源方案（单/双 PMIC）
- 确认 DDR 型号和容量
- 确认启动方式（eMMC/SD/SPI）

### 步骤 3：PCB 布局
- 核心区优先：RK3588 → DDR → PMIC → eMMC（紧凑放置）
- 接口区：USB/HDMI/网口等靠板边
- 模拟区：音频/ADC 远离数字区

### 步骤 4：PCB 布线
- 先布 DDR（最关键）
- 再布高速差分（USB/PCIe/HDMI）
- 再布电源（加粗走线/铺铜）
- 最后布普通信号

### 步骤 5：检查与验证
- DRC 检查
- 阻抗检查
- 电源完整性检查
- 送板打样（JLC/嘉立创等）

### 步骤 6：焊接与调试
- BGA 焊接建议找专业贴片厂
- 上电前用万用表检查电源对地阻抗
- 上电后先测各路电压是否正常
- 连接调试串口看启动日志

### 步骤 7：软件适配
- 基于 rockchip-linux/u-boot 修改 DDR 配置（如有变更）
- 修改设备树适配你的板子
- 编译内核和 U-Boot
- 烧录验证

## 六、更实际的替代方案

### 方案 A：买核心板 + 自画底板（推荐）
- 买现成 RK3588 核心板（如 FET3588-C、Orange Pi CM5）
- 核心板已处理好 DDR/PMIC/eMMC 等高难度部分
- 你只需画底板：引出 GPIO/I2C/SPI/USB/网口等
- 底板 4-6 层即可，难度大幅降低

### 方案 B：基于开源开发板修改
- 以 Orange Pi 5 Plus 或 Rock 5B 为蓝本
- 在其基础上裁剪/增加接口
- 参考其开源原理图（部分开发板有公开）

### 方案 C：全自制（不推荐新手）
- 从 RK3588 芯片级开始设计
- 需要高速 PCB 设计经验
- 需要 EDA 仿真工具
- 周期 3-6 个月

## 八、机器狗自制板卡建议

如果目标是给机器狗做控制板：

1. **建议用方案 A**：买 RK3588 核心板 + 自画底板
2. **底板需要**：
   - I2C 接口 ×4（IMU + 其他传感器）
   - SPI/CAN 接口 ×4（关节电机通信）
   - PWM 输出 ×8（执行器控制）
   - USB 3.0 ×2（摄像头 + 调试）
   - 千兆网口 ×1（上位机通信）
   - M.2 NVMe（模型权重存储）
3. **底板难度**：4-6 层 PCB，2-4 周可完成
4. **核心板选型**：优先选引出 GPIO 全的型号

这样既有了定制化的硬件，又避开了 DDR/PMIC/BGA 焊接这些最难的坑。
