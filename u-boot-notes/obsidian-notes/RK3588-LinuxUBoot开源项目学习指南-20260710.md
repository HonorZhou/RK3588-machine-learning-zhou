# RK3588 Linux/U-Boot 开源项目学习指南

## 一、官方开源仓库（GitHub）

### 1. rockchip-linux/u-boot
- **地址**: https://github.com/rockchip-linux/u-boot
- **分支**: `next-dev`（推荐）
- **说明**: 瑞芯微官方维护的 U-Boot 分支，基于 U-Boot 2017.09 深度适配，支持 RK3588 全系芯片
- **学习价值**: 了解瑞芯微对主线 U-Boot 的定制改动，包括启动流程、DDR 初始化、loader/spl 结构

### 2. rockchip-linux/kernel
- **地址**: https://github.com/rockchip-linux/kernel
- **分支**: `develop-5.10` 或 `develop-6.1`
- **说明**: 瑞芯微官方 Linux 内核分支，针对 RK3588 做了大量驱动适配
- **学习价值**: 研究设备树配置、NPU/GPU/VPU 驱动、RGA（2D加速）、PWM/GPIO 等外设驱动

### 3. rockchip-linux/rkbin
- **地址**: https://github.com/rockchip-linux/rkbin
- **说明**: 瑞芯微预编译的二进制固件（DDR init、bl31、bl32 等）
- **学习价值**: 理解 RK3588 启动链：ROM → TPL/SPL（DDR init）→ bl31（ATF）→ U-Boot → Kernel

### 4. rockchip-linux/build
- **地址**: https://github.com/rockchip-linux/build
- **说明**: 官方构建脚本，整合 U-Boot + Kernel + Rootfs 编译流程
- **学习价值**: 理解完整 SDK 的编译链路和打包逻辑

## 二、社区/第三方高质量项目

### 5. Orange Pi 5 Plus 官方 SDK
- **地址**: https://github.com/orangepi-xunlong/orangepi-build
- **说明**: 香橙派官方构建系统，支持 Orange Pi 5/5 Plus（RK3588S/RK3588）
- **学习价值**: 社区开发板文档完善，适合入门到进阶

### 6. Radxa Rock 5B SDK
- **地址**: https://github.com/radxa/kernel
- **说明**: Radxa（瑞莎）维护的 RK3588 内核分支
- **学习价值**: 另一个厂商视角的 RK3588 适配，可对比官方差异

### 7. armbian/build
- **地址**: https://github.com/armbian/build
- **说明**: Armbian 通用构建框架，支持多款 RK3588 开发板
- **学习价值**: 学习主流 Linux 发行版如何适配 RK3588，设备树管理思路

### 8. 主线 U-Boot（学习对比用）
- **地址**: https://github.com/u-boot/u-boot
- **说明**: U-Boot 官方主线，已包含部分 RK3588 支持（如 `rock5b-rk3588_defconfig`、`orangepi-5-plus-rk3588_defconfig`）
- **学习价值**: 对比主线和瑞芯微分支差异，理解 vendor patch 的意义

### 9. 主线 Linux Kernel
- **地址**: https://github.com/torvalds/linux
- **说明**: Linux 主线内核，已逐步合并 RK3588 支持
- **学习价值**: 追踪 RK3588 主线化进展，学习设备树规范和驱动框架

## 三、实战学习路线

### 阶段一：环境搭建与编译（1-2 周）
1. Ubuntu 22.04 LTS 环境
2. 安装交叉编译工具链：`gcc-aarch64-linux-gnu`
3. 克隆 rockchip-linux/u-boot（next-dev 分支）
4. 编译 U-Boot：
   ```
   make ARCH=arm64 rockchip_linux_defconfig
   make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- -j$(nproc)
   ```
5. 克隆 rockchip-linux/kernel（develop-5.10 分支）
6. 编译内核：
   ```
   make ARCH=arm64 rockchip_linux_defconfig
   make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- rk3588-evb.img -j$(nproc)
   ```

### 阶段二：启动流程深入（2-3 周）
1. 研究 RK3588 启动链：ROM Code → TPL → SPL → ATF(bl31) → U-Boot → Kernel
2. 阅读 `arch/arm/mach-rockchip/` 下的平台代码
3. 理解设备树：`arch/arm/dts/rk3588*.dtsi` 和板级 `.dts`
4. 烧录到 SD 卡/eMMC 实际启动验证

### 阶段三：驱动开发（3-4 周）
1. 从简单外设开始：LED（GPIO）、按键、UART
2. 进阶：I2C/SPI 设备驱动、PWM 调速
3. 高阶：DRM 显示框架、V4L2 视频采集、NPU（RKNPU）推理

### 阶段四：系统定制（2-3 周）
1. Buildroot 或 Debian 定制根文件系统
2. Recovery 系统制作与 OTA 升级
3. 安全启动（Secure Boot / FIT Image 签名）

## 五、关键概念清单

| 概念 | 说明 |
|------|------|
| rkbin | 瑞芯微预编译固件（DDR init/bl31/bl32） |
| TPL/SPL | U-Boot 两阶段加载器 |
| ATF (bl31) | ARM Trusted Firmware，安全监控模式 |
| FIT Image | Flattened Image Tree，打包 kernel+dtb+ramdisk |
| defconfig | 板级默认配置 |
| DTS/DTB | 设备树源码/二进制 |
| Buildroot | 轻量级 Linux 根文件系统构建框架 |
| RKNPU | RK3588 内置 6TOPS NPU |
| RGA | 2D 图形加速器 |
